## 🛠️ Tech Stack

- **Backend**: Python 3.8+, Flask 3.0.0, scikit-learn, numpy
- **Frontend**: React 18+, Axios, CSS3
- **ML Models**: Classifiers with ~82% average accuracy
- **Setup**: Easy setup scripts (setup.sh / setup.bat)

---

## 🚀 Quick Start

Choose any service and run:

```bash
cd [service-name]/backend

# Linux/Mac
bash setup.sh

# Windows
setup.bat

# Start the backend
python app.py
```

Backend runs on: `http://localhost:5000`

## 📋 Each Service Includes
